3  声子散射（逐模式）

基于 3.5 Å 力常数的全网格 Wigner 计算输出的逐模式数据（150 个不可约 q 点 × 384 支， 8×8×8 网格，300 K，含天然同位素），给出模式分辨的三声子散射率、同位素散射率与平均自由程。 三声子线宽 γ 与同位素线宽 γiso 直接取自 phono3py 的 kappa-m888.hdf5； 群速度由 FC2 经 phonopy 计算（频率与 Wigner 输出一致到 2.5×10-7 THz）。

3.1  关键数字

三声子散射率 τ-1 (THz)中位 1.49×10-1
同位素散射率 (THz)中位 6.1×10-3（低频段与 ω4 一致）

寿命与自由程呈强重尾分布：中位自由程仅 3 nm，但 1 % 的模超过 41 nm、最长可达 5.8 μm， 这些低频长寿命声学模主导了 κP，也解释了为什么 κP 对力常数高度敏感。

把 FC3 换成 3.0 Å 的拟合结果后：τ 中位 6.83 ps、自由程中位 3.16 nm、最长 4.05 μm（几乎不变）， 与"低频声子主要受 FC2 控制、κC 与低频散射对截断不敏感"的结论一致。

3.2  数据与复现

  • data/05_scattering/scattering_modes_c3_3p50.npz：逐模式数组 frequency / gamma / gamma_isotope / group_velocity / heat_capacity / mode_kappa_P_RTA （150×384，另含 weight、grid_point、qpoint、temperature、mesh）。
  • data/05_scattering/scattering_modes_c3_3p50.csv：逐模式派生量 （τ、τ-1、同位素率、|v|、mfp）。3.0 Å 的对应文件为 ..._c3_3p00.*。
  • scripts/plot_scattering.py：生成上图与 CSV（ python plot_scattering.py scattering_modes_c3_3p50.npz -o fig_scattering_c3_3p50）。
  • 单位约定：γ 为 THz，τ = 1/(2γ) 得 ps；|v| 为 THz·Å = Å/ps；mfp = |v|·τ（Å）÷10 = nm。
